## Eingang

Der Workflow erwartet eine strukturierte Aufgabe mit mindestens:

- title
- description
- priority
- project

Die genaue Definition steht in `contract.md`.

## Ausgang

Eine neue Trello-Karte mit:

- Titel
- Beschreibung
- Priorität
- Projektbezug

## Systeme

- n8n
- Trello
- GitHub
- JaMoKo Automation OS

1. Aufgabe per Webhook empfangen
