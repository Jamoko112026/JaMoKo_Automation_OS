# Workflow Contract

## Workflow

WF-0002 – Trello Board Setup

## Ziel

Ein neues oder leeres Trello-Board automatisch mit der definierten JaMoKo-Standardstruktur versehen.

## Eingaben

- Trello Board ID
- Definition der Standardlisten

## Ausgabe

Vollständig eingerichtetes JaMoKo-Trello-Board.

## Erfolgsbedingungen

- Alle Standardlisten wurden erstellt.
- Die Reihenfolge entspricht dem JaMoKo-Standard.
- Das Board ist für weitere Workflows vorbereitet.
