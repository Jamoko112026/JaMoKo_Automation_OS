# WF-0002 – Trello Board Setup

## Status

Released v1.0

## Zweck

Erstellt automatisch die Standardlisten eines JaMoKo-Trello-Boards.

## Ablauf

1. Liest das Zielboard.
2. Definiert die JaMoKo-Standardlisten.
3. Erstellt fehlende Listen im Trello-Board.

## Ergebnis

Nach erfolgreicher Ausführung besitzt das Board die definierte JaMoKo-Standardstruktur.

## Voraussetzungen

- Trello-Credentials in n8n
- Zugriff auf das Zielboard

## Verwendete Dienste

- n8n
- Trello

## Version

v1.0
