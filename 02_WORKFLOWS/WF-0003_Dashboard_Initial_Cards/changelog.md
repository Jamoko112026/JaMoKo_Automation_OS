# Changelog

## v1.0 – 2026-07-29

- Erste funktionsfähige Version veröffentlicht.
- Trello-Board wird dynamisch ausgelesen.
- Vorhandene Listen werden automatisch erkannt.
- Dashboard-Karten werden im Workflow definiert.
- Karten werden anhand des Listennamens der richtigen Listen-ID zugeordnet.
- Karten werden erfolgreich im Trello-Board erstellt.
- Bekannte Einschränkung dokumentiert: erneute Ausführung erzeugt Duplikate.
