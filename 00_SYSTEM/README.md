# JaMoKo Automation OS

## Mission

JaMoKo Automation OS ist die technische Plattform für alle Automationen von JaMoKo.

Es verbindet ChatGPT, n8n, Trello, GitHub und weitere Dienste zu einem nachvollziehbaren, dokumentierten und reproduzierbaren System.

## Ziel

Automatisierungen sollen nicht aus einzelnen Workflows bestehen, sondern aus klar definierten Modulen mit Standards, Verträgen und Versionierung.

## Grundprinzipien

- Ein Workflow = eine klar definierte Aufgabe
- Dokumentation gehört zur Entwicklung
- Standards entstehen aus funktionierenden Lösungen
- Jede Änderung ist versioniert
- Wiederverwendbarkeit vor Einzellösung

## Aufbau

- `00_SYSTEM` – Systemdokumentation
- `01_REGISTRY` – Register
- `02_WORKFLOWS` – Workflows
- `03_SERVICES` – Integrationen
- `04_STANDARDS` – Standards
- `05_TEMPLATES` – Vorlagen
- `06_EXPORTS` – Exporte
- `07_DECISIONS` – Architekturentscheidungen
- `08_REFERENCE` – Referenzen
- `99_ARCHIVE` – Archiv

## Aktueller Stand

Version: 0.1.0

Der erste Workflow (`WF-0001 – Task Intake`) bildet die Grundlage für alle weiteren Automationen.
